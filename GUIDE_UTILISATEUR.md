## 🛒 Utilisation du Panier

### Ajouter des articles

1. Cliquez sur le bouton **"Ajouter au Panier"** sous un produit
2. L'article apparaît dans la sidebar droite
3. Le total se met à jour automatiquement

### Modifier la quantité

1. Ouvrez la sidebar du panier (icône panier en haut)
2. Utilisez **+ / -** pour ajuster la quantité
3. Cliquez **"Retirer"** pour supprimer l'article

### Voir le total

```
Sous-total: 25,000 FCFA
Livraison: Calculée à la commande
TOTAL: Voir au moment du paiement
```

---

## 📋 Passer Commande

### Étape 1: Ouvrir le formulaire

1. Cliquez sur **"Passer Commande"** (en bas du panier)
2. Le formulaire de validation s'affiche

### Étape 2: Remplir le formulaire

**✅ OBLIGATOIRE:**
- **Téléphone:** Numéro à 8+ chiffres
  - Exemple: `07 68 24 59 17` ou `+225 07 68 24 59 17`
  - ⚠️ Sans ce champ, la commande est bloquée

**📝 OPTIONNEL (peut être vide):**
- Prénom
- Nom
- Lieu / Ville (pour calcul livraison)
- Note / Commentaire

### Étape 3: Calcul livraison

La livraison est **automatiquement calculée** selon votre lieu:

```
Plateau, Cocody, Treichville...   → 0 FCFA (Gratuit)
Bassam, Anyama, Zone Industrielle → 1000 FCFA
Autres villes                      → 2000 FCFA
```

> **Astuce:** Entrez votre lieu pour voir la livraison se mettre à jour!

### Étape 4: Valider

1. Cliquez **"Valider Commande"**
2. **2 options:**
   - **Envoyer par WhatsApp:** Message automatique au vendeur
   - **Copier les détails:** Coller ailleurs si besoin

## 💬 Option WhatsApp

### Qu'est-ce qui se passe?

1. Vous cliquez **"Envoyer par WhatsApp"**
2. Un message est créé avec:
   - ✓ Tous vos articles
   - ✓ Les prix
   - ✓ Vos coordonnées (si remplies)
   - ✓ La livraison
   - ✓ Le TOTAL

3. Le message s'ouvre dans WhatsApp (ou Web WhatsApp)

### Exemple de message

```
Bonjour, voici ma commande:

ARTICLES:
- Produit A (2x) : 10,000 FCFA
- Produit B (1x) : 15,000 FCFA

Sous-total: 25,000 FCFA
Livraison (Plateau): 0 FCFA
TOTAL: 25,000 FCFA

Prénom: Jean
Téléphone: 07 68 24 59 17
Lieu: Plateau

Merci!
```

## ❓ FAQ

### **Q: J'ai oublié de remplir mon prénom, ça pose problème?**
**A:** Non! Seul le téléphone est obligatoire. Prénom/Nom/Lieu sont optionnels.

### **Q: Comment savoir si la livraison est gratuite?**
**A:** Entrez votre lieu dans le formulaire. Si 0 FCFA s'affiche → **Gratuit!**

### **Q: Que faire si le WhatsApp ne s'ouvre pas?**
**A:** Cliquez **"Copier les détails"** et collez dans WhatsApp manuellement.

### **Q: Puis-je modifier ma commande après?**
**A:** Oui, contactez le vendeur directement par WhatsApp.

### **Q: Les prix incluent la livraison?**
**A:** Non. La livraison est **ajoutée** au total selon votre lieu.

### **Q: Comment payer?**
**A:** Après validation WhatsApp, le vendeur vous donnera les instructions de paiement.
